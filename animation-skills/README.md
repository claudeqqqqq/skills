# Animation skills

Third-party Claude skills for Roblox story videos and general animation, copied here from their original repos (November 2026). Each folder keeps the original license. Video and audio sample files (.mp4, .mov, .wav) were left out to keep the branch small.

These are not part of this repo's plugin and are not linked by `scripts/link-skills.sh`. To use one, copy its folder into `~/.claude/skills/`. Read each skill and its scripts before running it.

Two entries need their whole original repo to work: `celoalze/roblox-in-this-town-threejs` and `hassancs91/claude-faceless-shorts-creator`. Clone those repos instead of copying the folder alone.
